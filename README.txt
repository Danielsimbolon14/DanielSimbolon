DANIEL SIMBOLON — ELECTRICAL ENGINEER PORTFOLIO

HOW TO USE
1. Extract the folder.
2. Open index.html in Chrome/Edge/Firefox.
3. Edit the text directly in index.html if needed.
4. Replace images inside assets/ while keeping the filenames, or update the image paths in index.html.
5. Replace your email and LinkedIn in the Contact section.

DESIGN
Inspired by the structure and presentation style of Marco Volpini's Electrical Engineering portfolio: strong hero statement, featured project cards, experience, grouped skills and contact section. It is an original implementation for Daniel's engineering work, not a copy of the source site's code.

PROJECT IMAGES
The provided gallery screenshots with visible phone dates were cleaned/cropped before inclusion in the portfolio assets.
